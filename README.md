# XMU 厦大畅课助手

厦门大学畅课平台（`lnt.xmu.edu.cn`）的浏览器用户脚本。

## 安装

**[点此安装脚本](https://raw.githubusercontent.com/Lormited/XMU-TronClass-Helper/main/XMU-TronClass-Helper.user.js)**（需先装好 Tampermonkey 等用户脚本管理器）

## 功能

**资料下载**：课程页右下角悬浮按钮；列出本课程 可下载/不可下载 所有文件，勾选下载。

**签到列表**：将首页「常用入口」替换为「正在签到」，可显示当前正在进行的签到与对应**魔法数字**。

**待办排序**：将首页待办列表中的作业按截止时间升序排列。

**界面精简**：可选隐藏 侧栏、底栏、AI 助手、滚动条。

**顶栏精简**：可选隐藏 我的主页、日历、通知、帮助、账号信息、校徽、课程中心、分隔栏等。

**页面自适应**：按窗口大小整体缩放首页，一屏显示更多；开启后首页禁止全屏滚动，待办和课程栏不影响。

**课程栏优化**：课程横向列表点击后会整页翻动，且支持鼠标滚轮滑动。

**校徽回主页**：点左上角校徽回主页，不再跳数字化教学平台。

**设置面板**：页面右侧边缘齿轮按钮，可对所有功能进行开关。

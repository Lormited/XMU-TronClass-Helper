# XMU 厦大畅课助手

厦门大学畅课平台（`lnt.xmu.edu.cn`）的浏览器用户脚本。把上课常用的几件事收拢到一处：下载课程资料、查看正在进行的签到与签到码、精简界面、让首页一屏显示更多、翻动课程列表。所有功能都能在右侧设置面板里随时开关。

## 安装

**[在 Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/596810)**（需先装好 Tampermonkey 等用户脚本管理器）

## 功能

### 资料下载

课程页右下角的悬浮按钮。点开自动列出本课程所有可下载资料，勾选后批量下载，逐个进行并显示进度与成功 / 失败数量。自动跳过已删除与重复项，文件名会清理非法字符。

### 签到列表

把首页「常用入口」替换为「正在签到」列表。每条显示课程名与点名方式，右侧是签到码和去签到的圆形箭头；已签到的条目换成绿色完成图标，不再可点。

**签到码**只对数字点名有效，取自 `/api/rollcall/{id}/student_rollcalls` 的 `number_code`，以虚线胶囊形式贴在条目右侧。是否为「已签到」看接口返回的 `status`——注意 `student_status` 即使在已签到时也仍是 `on_call`，不能拿来判定。

列表只在内容变化时重绘，不会因为轮询把鼠标底下的元素换掉。

### 界面精简

四个独立开关：隐藏侧栏、底栏、AI 助手、滚动条。关闭时精确还原。

### 顶栏精简

把顶栏按「入口」拆成一个个独立开关，点选即可隐藏对应项，平台改版一般无需改代码。

聚合的单位是**语义入口**，不是递归到叶子节点——所以「我的主页」「日历」「通知」「帮助」「账号信息」各自是一个开关，而不会被拆成一堆没有文字的图标。校徽与「课程中心」保持两个开关；日历左边、帮助右边那两条分隔栏也能单独关闭；「更多」是折叠菜单的入口，不单独提供开关。

开关配置按元素的结构签名（标签 + 祖先 class + 文字）保存，不依赖顺序，所以通知角标消失、窗口宽度变化都不会让开关错位。

### 页面自适应

仅首页。以 1440 × 860 为基准把主内容区整体缩放（0.7 ~ 1.6），一屏铺满。开启后首页禁用整页滚轮滚动，真正能滚的区域仍放行；离开首页自动还原。

### 课程栏翻页

仅首页。课程横向列表整屏翻页并带平滑动画，支持鼠标滚轮，箭头禁用状态自动维护。

## 设置面板

页面右侧边缘的齿轮按钮。每个功能一行开关，有子选项的（签到列表、界面精简、顶栏精简）会在下方展开标签。改动即时生效，无需刷新。

## 可调参数

脚本顶部的常量，想自己试效果改这里就行：

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| `COURSE_STEP` | 0.97 | 课程栏每次翻页的比例，1 = 正好一屏 |
| `COURSE_DUR` | 280 | 翻页动画时长（毫秒） |
| `WHEEL_STEP` | 1.6 | 课程栏滚轮灵敏度 |
| `FIT_W` / `FIT_H` | 1440 / 860 | 页面自适应的设计基准 |
| `FIT_MIN` / `FIT_MAX` | 0.7 / 1.6 | 缩放上下限 |
| `POLL` | 1300 | 轮询间隔（毫秒） |

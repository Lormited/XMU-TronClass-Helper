# XMU 厦大畅课助手

厦门大学畅课平台（`lnt.xmu.edu.cn`）的浏览器用户脚本。

## 安装

**[在 Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/596810)**（需先装好 Tampermonkey 等用户脚本管理器）

## 功能

**资料下载**  ：课程页右下角悬浮按钮；列出本课程可下载资料，勾选后批量下载。

**签到列表**  ：将首页「常用入口」替换为「正在签到」，可显示当前正在进行的签到与对应**魔法数字**。

**界面精简**  ：可选隐藏：侧栏、底栏、AI 助手、滚动条。

**顶栏精简**  ：可选隐藏：我的主页、日历、通知、帮助、账号信息、校徽、课程中心等。

**页面自适应**  ：按屏幕比例整体缩放首页，一屏显示更多；开启后首页禁止滚动，待办和课程栏不影响。

**课程栏翻页**  ：课程横向列表整页翻动，带平滑动画，支持鼠标滚轮。

**设置面板**  ：页面右侧边缘齿轮按钮，可对所有功能进行开关。
